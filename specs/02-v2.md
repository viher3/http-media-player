# V2 — Implementation notes

The V2 scope is defined in section 3 of [01-mvp.md](01-mvp.md) and is fully implemented. Decisions and deviations from that text:

- **Password hashing:** `scrypt` from `node:crypto` instead of argon2 (no extra native dependency).
- **Gapless:** near-gapless transitions using two `<video>` elements (active + standby that preloads the next audio track). Strict gapless would require Web Audio with full decoding.
- **Videos:** grouped by folder; the `SxxExx` series pattern is not detected.
- **Artist aliases:** normalisation is heuristic (accents, case, leading "the", `&` ≡ `and`); there is no editable alias table.
- **Resume position:** stored for videos and audio longer than 20 minutes.
- **Users:** first start asks for the administrator account; the whole API requires a session except `/api/auth/*`. Manual rescans require admin.
- **Visualizer:** enabling it routes audio through an `AudioContext` until the page is reloaded.
- **Playlists, favourites and history** reference files by path (not `media.id`), so entries survive a file disappearing and returning ("unavailable" state).
- **Live updates:** chokidar watcher (optional polling) + Server-Sent Events to refresh the UI.
